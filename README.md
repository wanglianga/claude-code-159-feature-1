# 邻里药箱 · 社区共享借用 / 效期提醒 / 临期优先流转 / 邻里互助（演示）

一个纯前端演示应用：居民登记家中多余但**未拆封**的常备非处方耗材（退热贴、碘伏、纱布、创可贴、口罩、体温计电池等），
经社区志愿者审核发布后，邻居可按症状场景申请借用，支持自取 / 志愿者代送 / 邻居门口无接触交接，交接拍照确认，
并按约定归还或补充。效期临近、多人争抢、超时未取、配送延误、共享人撤回、包装破损与疑似不适反应均有对应处理流程。

**本次新增：临期（≤10 天）物品优先流转闭环**——临期清单定向推荐、交接强制使用前检查确认、借出后定时回访使用/剩余/回收、无人借用提醒共享人取回或报废。

> **社区只做物品流转和风险提醒，不做诊断建议。**
> 处方药、拆封药品、冷链药品、过期/包装破损物品**一律不能进入共享**。共享物品不替代就医。

技术栈：Vue 3（`<script setup>`）+ TypeScript + Pinia + Vue Router + Vite + Vitest。
所有数据保存在浏览器 `localStorage`，无后端依赖；底部“演示时钟”可快进，用于演示效期、超时、临期回访与延误。

## 本地启动

### 方式一：Node 直接运行（开发）

```bash
npm install        # 如本机 npm 缓存权限异常，可加 --cache /tmp/npm-cache
npm run dev        # http://localhost:5173
```

### 方式二：Docker / Compose 一键启动（推荐，无需本机 Node 环境）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
docker compose logs -f medkit-web
docker compose down              # 停止
```

镜像为多阶段构建（`node:20-alpine` 内执行类型检查+生产构建 → `nginx:1.27-alpine` 托管静态产物），
也可单独构建：

```bash
docker build -t community-medkit-share .
docker run --rm -p 8080:80 community-medkit-share
```

其他命令：

```bash
npm run typecheck  # vue-tsc 严格类型检查
npm run test       # Vitest 单元/流程/页面冒烟测试（3 个文件 27 个用例）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建产物（http://localhost:4173）
```

## 页面与角色视图

- **药箱大厅 `/hall`**：按四个急用场景筛选 + 关键词搜索；仅展示审核通过且在有效期内的物品；**临期物品带红色“临期优先流转”提示并排在最前**。
- **物品详情 `/items/:id`**：临期物品显示红字流转横幅；每次借用强制逐项勾选 **来源 / 效期 / 包装状态 / 适用限制**；可提交包装破损/疑似不适反馈；同页展示借用记录、反馈与完整时间线。
- **登记共享 `/register`**：品名、规格、有效期、存放条件、未开封承诺、数量、取用地点、适用场景；实时规则校验，禁入品提交即拦截，≤10 天给出临期流转警示。
- **我的共享 `/my-shares`**：确认/婉拒申请、发起交接、**临期交接时代借用人逐项确认效期与使用前检查**；临期物品展示社区“取回/报废”提醒，可一键取回自行处理。
- **我的借用 `/my-borrows`**：候补、取件、**临期交接未完成四项使用前检查不能确认收到**、到期回访（是否使用/是否剩余/是否回收）、归还/补充闭环。
- **志愿者工作台 `/volunteer`**：审核、代送（送达时完成借用人临期确认）、报备延误/改派、超时催办与释放、候补递补。
- **社区工作台 `/staff`**：默认进入**临期优先流转专区**；另有风险看板、过期报废、60/30 天效期分级、“其他耗材”双重复核、任选物品查看完整链路时间线。
- **互助边界 `/guide`**：做什么/不做什么、四类禁入、借用前四项确认、临期流转五步规则、七种异常处理。

## 临期优先流转规则（本题核心，可在 `src/rules.ts`、`src/stores/medkit.ts` 核验）

- **10 天红线（`EXPIRY_PRIORITY_DAYS`）**：在架物品距到期 ≤10 天自动进入工作人员“临期优先流转”清单（另有 60/30 天黄/橙预警）。
- **工作人员清单三件事**：① **临期清单**（物品、到期日、可借量、借出盯办、候补数）；② **可使用场景**（按孩子夜间发烧/老人伤口/缺口罩/居家护理给出“尽快使用、不替代就医”话术）；
  ③ **建议优先推荐范围**——登记过急用场景的家庭、同场景正在候补且原物品无余量的邻居（系统自动匹配）、24–48 小时内确定要用的人，不推荐“先囤着”。
- **无人借用 → 提醒取回/报废**：到期前 5 天（`NEAR_EXPIRY_OWNER_NOTICE_DAYS`）仍无锁定借用且无候补，清单标红，工作人员一键提醒共享人取回在到期日前使用或交社区报废，提醒动作写入时间线；共享人也可在“我的共享”自行取回。
- **有人借用 → 交接强制确认**：交接页红字标明到期日，借用人必须逐项勾选并留痕（`NearExpiryAck`）：
  ① 核对包装标注到期日；② 检查整盒及独立小包装封签完好；③ 检查无受潮/变色/污渍/渗漏/破损/异味；④ 承诺到期日前使用、到期后不再使用。
  任一不满足当场拒收。志愿者代送/共享人代操作时当面核对，**确认记录仍记在借用人名下**，与交接照片一并留痕。
- **借出后定时回访**：交接完成即设定 24 小时（`NEAR_EXPIRY_FOLLOWUP_HOURS`）后回访，页面提醒借用人反馈三件事：**是否使用、是否剩余、是否需要社区回收**；
  到点未反馈看板提示，超过 12 小时宽限期红色催收；工作人员可电话回访后代登记。
- **按反馈分流闭环**：已全部使用 → 回访后自动核销；部分使用/未使用且不要回收 → 走归还未拆封/补充新品；需要回收 → 可约**志愿者上门取**或**自行送到共享柜/居委会**，
  工作人员确认收回后按“社区回收”闭环（`community_recycle`），**回收物品不再回到流通**，避免临期物品长期停留在个人家中。
- **全程留痕**：进入清单、取回提醒、借用人确认、回访反馈、社区回收均为同一物品时间线上的独立事件（`near_expiry_*`、`use_feedback`、`recycled`），三端记录对得上、可追溯。

## 其他关键业务规则

- **库存锁定**：申请初始为“候补”；共享人/志愿者确认后锁定数量，余量不足不能确认；取消或闭环后释放，候补按申请时间递补。
- **取件时限**：确认后 24 小时（`PICKUP_WINDOW_HOURS`）未完成交接 → 看板标红，可催办后取消释放给候补。
- **配送 SLA**：志愿者代送 6 小时（`DELIVERY_SLA_HOURS`）未完成 → 自动标红，可报备原因或由工作人员改派。
- **反馈即隔离**：包装破损/疑似不适反馈提交后物品立即隔离，等待与交接中申请全部取消（已取走的保留）；疑似不适明确引导停止使用并就医。

## 建议的手工演示路径（约 4 分钟）

1. 默认身份**李建国**打开大厅：10 天到期的“儿童退热贴（临期）”排在最前、带红色临期提示；点进去看红字流转横幅。
2. 切**赵磊（社区工作人员）**：工作台默认在“临期优先流转”专区——i13 退热贴（10 天，无人借用，含可使用场景与优先推荐范围）、i14 碘伏（3 天，已借出 r6 回访逾期）、i15 纱布（6 天，待社区回收）。
3. 在 i13 卡片点“提醒共享人取回或报废”观察留痕；在回访队列点“催办”或“电话回访代登记”；在回收队列确认 uf1 回收闭环。
4. 用底部 **+1天/+3天** 快进：看 i13 从 10 天→进入 5 天提醒线；看 r6 回访逾期小时数增加。
5. 切**李建国 → 我的借用**：对 r6 提交回访（选“部分使用+志愿者上门取”），切回工作人员确认回收；或自己新申请 i13，走到交接页体验**不勾完四项不能确认收到**。
6. 切**陈芳（志愿者）**：对一笔临期配送任务送达，体验代借用人完成临期确认（记录记在借用人名下）。
7. 打开任一临期物品详情页，用“全流程追溯”查看 登记→审核→临期确认→回访→回收 的完整记录链；随时“重置演示数据”还原。
