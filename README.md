# 邻里药箱 · 社区共享借用 / 效期提醒 / 邻里互助（演示）

一个纯前端演示应用：居民登记家中多余但**未拆封**的常备非处方耗材（退热贴、碘伏、纱布、创可贴、口罩、体温计电池等），
经社区志愿者审核发布后，邻居可按症状场景申请借用，支持自取 / 志愿者代送 / 邻居门口无接触交接，交接拍照确认，
并按约定归还或补充。效期临近、多人争抢、超时未取、配送延误、共享人撤回、包装破损与疑似不适反应均有对应处理流程。

> **社区只做物品流转和风险提醒，不做诊断建议。**
> 处方药、拆封药品、冷链药品、过期/包装破损物品**一律不能进入共享**。共享物品不替代就医。

技术栈：Vue 3（`<script setup>`）+ TypeScript + Pinia + Vue Router + Vite + Vitest。
所有数据保存在浏览器 `localStorage`，无后端依赖；底部“演示时钟”可快进，用于演示效期、超时与延误。

## 本地启动

```bash
npm install        # 如本机 npm 缓存权限异常，可加 --cache /tmp/npm-cache
npm run dev        # http://localhost:5173
```


## 页面与角色视图

- **药箱大厅 `/hall`**：按四个急用场景筛选（孩子夜间发烧 / 老人小伤口 / 临时缺口罩 / 居家护理缺耗材）+ 关键词搜索；
  仅展示审核通过且在有效期内的物品；卡片显示来源、规格、效期分级、未开封包装、存放条件、余量/候补人数、取用地点。
- **物品详情 `/items/:id`**：每次借用强制逐项勾选确认 **来源 / 效期 / 包装状态 / 适用限制**；可提交“包装破损 / 疑似不适”反馈；
  同页展示该物品的借用记录、风险反馈与**登记→审核→借出→交接→归还/报废→反馈**完整时间线。
- **登记共享 `/register`**：填写品名、规格、有效期、存放条件、是否整盒未开封、可借数量、取用地点、适用场景；
  实时规则校验，禁入品（处方药/口服注射药、拆封、冷链、过期、≤30 天临期）提交即被拦截。
- **我的共享 `/my-shares`**：登记人物品状态与审核意见；确认/婉拒借用申请、发起交接、拍照确认、撤回（候补自动取消，进行中继续履行）。
- **我的借用 `/my-borrows`**：候补、取件开始/拍照确认收到、超 24h 未取红色警告、登记归还未拆封 / 补充新品 / 赠予核销。
- **志愿者工作台 `/volunteer`**：审核（机器规则二次提示）、配送拍照/报备延误/改派、超时催办与释放、候补递补确认。
- **社区工作台 `/staff`**：风险看板统计、开放反馈处置（报废同批次或核验后重新发布）、过期报废、60/30 天效期分级、
  “其他耗材”双重复核、任选物品查看完整链路时间线。
- **互助边界 `/guide`**：把“做什么/不做什么”、四类禁入、借用前四项确认、流程与七种异常处理说清楚。

## 关键业务规则（可在 `src/rules.ts` 与 `src/stores/medkit.ts` 核验）

- **库存锁定**：申请初始为“候补”；共享人/志愿者确认后锁定数量，余量不足不能确认，避免同一件物品被多人同时拿走；
  取消或闭环（归还/补充/赠予）后释放，候补按申请时间递补。
- **效期**：60 天黄色预警、30 天红色预警、过期大厅自动禁借并进入工作人员“待报废”清单；效期按自然日计算。
- **取件时限**：确认后 24 小时（`PICKUP_WINDOW_HOURS`）未完成交接 → 志愿者/工作人员看板标红，可催办后取消释放给候补。
- **配送 SLA**：志愿者代送 6 小时（`DELIVERY_SLA_HOURS`）未完成 → 自动标红，志愿者报备原因，工作人员可改派兜底。
- **撤回**：候补申请自动取消并通知；已确认/交接中/已取走的借用继续履行，不再接受新申请。
- **反馈即隔离**：包装破损、疑似不适反应提交后物品立即隔离，等待/确认/交接中的申请全部取消（已取走的保留）；
  疑似不适反馈的返回文案明确引导**停止使用并就医**，社区不下诊断结论；工作人员核查后决定报废或重新发布。
- **全链路串联**：每个动作都写入同一物品的时间线（`TimelineEvent`），三个角色视角不同但记录对得上、可追溯。

## 建议的手工演示路径（约 3 分钟）

1. 默认身份**李建国**打开大厅，点“孩子夜间发烧”场景，查看退热贴的来源/效期/包装/限制，勾选四项确认后申请。
2. 切到**陈芳（志愿者）**：工作台审核“儿童退热贴”和临期碘伏（尝试通过临期品观察规则提示）；在“配送任务”报备延误、拍照完成口罩配送。
3. 点底部 **+1天 / +3天**：回到志愿者页看“超时未取”增加，取消一笔释放给候补；切工作人员看“效期与报废”出现过期物品，执行报废。
4. 以**李建国**在“我的借用”对已取走的电池选择“补充同规格新品”闭环，观察候补递补提示。
5. 物品详情页点“反馈包装破损/疑似不适”，切**赵磊（工作人员）**在风险看板核查报废或解封；用“全链路追溯”查看整件物品的完整记录链。
6. 任意时点用右上角身份切换体会三类角色视图差异，或点“重置演示数据”还原。
