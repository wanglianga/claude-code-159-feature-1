# 邻里药箱 · 社区共享借用 / 效期提醒 / 临期优先流转 / 邻里互助（演示）

一个纯前端演示应用：居民登记家中多余但**未拆封**的常备非处方耗材（退热贴、碘伏、纱布、创可贴、口罩、体温计电池等），
经社区志愿者审核发布后，邻居可按症状场景申请借用，支持自取 / 志愿者代送 / 邻居门口无接触交接，交接拍照确认，
并按约定归还或补充。效期临近、多人争抢、超时未取、配送延误、共享人撤回、包装破损与疑似不适反应均有对应处理流程。

**本期新增：临近效期物品的优先流转闭环。** 居民共享的退热贴还有十天到期时：

- **工作人员看板**：临期清单（≤30 天且有余量）逐件展示**可使用场景、建议优先推荐范围**（如“当晚有发热儿童的家庭”），支持一键定向推荐；
  距到期 ≤7 天仍无人借用时，提醒共享人**取回继续自用或申请社区报废**；共享人也可在“我的共享”主动申请报废。
- **交接页**：明确**有效期与使用前检查要求**（封签完好、按条件保存、外观无异常、过期停用等），由借用人**逐项勾选确认并留痕**（确认时间 + 效期日期写入物品时间线），未确认不能完成交接。
- **借出后用后追踪**：约定取走后 **72 小时**内提醒借用人反馈三件事——**是否使用、是否剩余、是否需要社区回收**；逾期未反馈在工作人员看板标红并可催办；
  未使用/有剩余的由**社区回收统一报废并闭环**，避免临期物品长期滞留在个人家中。

> **社区只做物品流转和风险提醒，不做诊断建议。**
> 处方药、拆封药品、冷链药品、过期/包装破损物品**一律不能进入共享**。共享物品不替代就医。

技术栈：Vue 3（`<script setup>`）+ TypeScript + Pinia + Vue Router + Vite + Vitest；生产镜像为 nginx 静态托管。
所有数据保存在浏览器 `localStorage`，无后端依赖；底部“演示时钟”可快进，用于演示效期、超时、用后反馈到期等。

## 本地启动

### 方式一：Docker 一键启动（推荐）

```bash
docker compose up -d --build     # 构建并启动
# 打开 http://localhost:8080
docker compose logs -f medkit-web
docker compose down              # 停止
```

镜像为多阶段构建（Node 20 构建 → nginx:1.27-alpine 托管 `dist/`），也可直接：

```bash
docker build -t community-medkit-share .
docker run --rm -p 8080:80 community-medkit-share
```

### 方式二：本地开发

```bash
npm install        # 如本机 npm 缓存权限异常，可加 --cache /tmp/npm-cache
npm run dev        # http://localhost:5173
```

其他命令：

```bash
npm run typecheck  # vue-tsc 严格类型检查
npm run test       # Vitest 单元/流程/页面冒烟测试（3 个文件 37 个用例）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建产物
```

## 页面与角色视图

- **药箱大厅 `/hall`**：按四个急用场景筛选 + 关键词搜索；仅展示审核通过且在有效期内的物品；**临期物品（≤30天）排序靠前并有“临期优先流转”显著提示**；卡片显示来源、规格、效期分级、未开封包装、存放条件、余量/候补人数、取用地点。
- **物品详情 `/items/:id`**：临期物品显著展示**使用前检查要求**与**建议优先推荐范围**；每次借用强制逐项勾选确认 **来源 / 效期 / 包装状态 / 适用限制**；可提交“包装破损 / 疑似不适”反馈；同页展示借用记录、风险反馈与完整时间线。
- **登记共享 `/register`**：填写品名、规格、有效期、存放条件、是否整盒未开封、可借数量、取用地点、适用场景；实时规则校验，禁入品（处方药/口服注射药、拆封、冷链、过期、数量异常）提交即被拦截；≤30 天临期为警告并提示将进入优先流转清单。
- **我的共享 `/my-shares`**：登记物品状态与审核意见；临期物品展示优先流转提示；≤7 天无人借用可**申请社区报废**；确认/婉拒申请、发起交接、拍照确认、撤回（候补自动取消，进行中继续履行；临期交接须由借用人本人确认）。
- **我的借用 `/my-borrows`**：候补、取件开始/拍照确认；**临期交接时逐项勾选效期与使用前检查要求方可确认收到**；已取走的临期借用在约定时间前/后展示**用后反馈表单（是否使用 / 使用数量 / 剩余数量 / 是否需要社区回收 / 备注）**；待回收期间不能自行闭环；超 24h 未取红色警告；常规借用登记归还/补充/赠予。
- **志愿者工作台 `/volunteer`**：审核（机器规则二次提示）、配送临期物品时确认已当面交代效期与检查要求、拍照/报备延误/改派、超时催办与释放、候补协调、**到期待反馈催办**。
- **社区工作台 `/staff`**：
  - **临期优先流转（默认页）**：① 临期清单：逐件列场景与优先推荐范围、可借余量、定向推荐、≤7 天提醒共享人取回/报废、确认共享人报废申请；
    ② 借出追踪：借用人效期确认留痕、72 小时到期未反馈标红催办、已反馈待回收的登记“社区回收并闭环”；
  - 风险看板、开放反馈处置（报废同批次或核验后重新发布）、过期报废、60/30 天效期分级、“其他耗材”双重复核、任选物品查看完整链路时间线。
- **互助边界 `/guide`**：把“做什么/不做什么”、四类禁入、借用前四项确认、临期交接与用后追踪、流程与各种异常处理说清楚。

## 关键业务规则（可在 `src/rules.ts` 与 `src/stores/medkit.ts` 核验）

- **库存锁定**：申请初始为“候补”；共享人/志愿者确认后锁定数量，余量不足不能确认；取消或闭环（归还/补充/赠予/回收）后释放，候补按申请时间递补。
- **效期**：60 天黄色预警、30 天红色预警并进入临期优先流转（`NEAR_EXPIRY_PRIORITY_DAYS=30`）、过期大厅自动禁借并进入工作人员“待报废”清单；效期按自然日计算。
- **临期无人借用**：距到期 ≤7 天（`OWNER_RETRIEVE_REMIND_DAYS`）仍有余量时，工作人员提醒共享人取回或申请报废；共享人本人也可发起报废申请，工作人员确认后执行。
- **临期交接确认**：完成交接拍照时，若物品 ≤30 天到期，必须携带借用人的“效期 + 使用前检查”确认；系统记录确认时间、效期日期，并生成取走后 72 小时（`NEAR_EXPIRY_FEEDBACK_HOURS`）的反馈约定。
- **用后反馈与回收**：临期借用未反馈不能闭环；反馈“需要回收”的只能由工作人员登记 `community_recycle` 闭环（回收剩余、统一报废，余量清零时物品同步报废）；数量校验防止“使用+剩余 > 借用数量”。
- **取件时限**：确认后 24 小时（`PICKUP_WINDOW_HOURS`）未完成交接 → 标红，可催办后取消释放给候补。
- **配送 SLA**：志愿者代送 6 小时（`DELIVERY_SLA_HOURS`）未完成 → 自动标红，可报备/改派。
- **撤回 / 反馈即隔离 / 全链路串联**：沿用原规则；临期确认、反馈催办、用后反馈、取回提醒、报废申请、社区回收均写入同一物品时间线（`TimelineEvent`）。
